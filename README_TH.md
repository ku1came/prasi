# Prism Roleplay — เวอร์ชันเว็บส่วนตัว

โปรเจกต์นี้เป็นเว็บแอป React/Vite สำหรับใช้งาน AI Chat และ Roleplay บน PC/มือถือ

## เรื่องความเป็นส่วนตัวที่ควรรู้

- ตัวแอปนี้ **ยังไม่มีระบบบัญชี/รหัสผ่านในตัว** เพราะการป้องกันหน้าเว็บด้วยรหัสผ่านที่เขียนไว้ใน JavaScript ไม่ปลอดภัย
- สำหรับเว็บออนไลน์ส่วนตัว ให้ใช้ **Cloudflare Pages + Cloudflare Access** เพื่อบังคับยืนยันตัวตนที่ขอบเครือข่ายก่อนส่งหน้าเว็บให้ผู้ใช้
- แนะนำตั้ง Access เป็น One-time PIN และอนุญาตเฉพาะอีเมลของคุณ
- ห้ามใส่ API Key ลงใน source code หรือไฟล์ที่เผยแพร่
- API Key ในหน้าตั้งค่าจะอยู่ในหน่วยความจำของแท็บเบราว์เซอร์เท่านั้น และหายเมื่อรีเฟรช แต่การเรียก API จากเบราว์เซอร์หมายความว่าคีย์อาจถูกตรวจดูได้จากเครื่องที่ใช้งาน
- ประวัติแชตและตัวละครอยู่ใน state ของหน้าเว็บ ไม่ได้บันทึกลงฐานข้อมูล เมื่อรีเฟรชหน้าเว็บจะหาย
- การเชื่อม Local AI จากเว็บออนไลน์ต้องตั้งค่าให้เครื่อง Local AI เข้าถึงได้อย่างปลอดภัยและรองรับ CORS; `localhost` ในเบราว์เซอร์หมายถึงเครื่องของผู้ใช้ที่เปิดเว็บ ไม่ใช่เซิร์ฟเวอร์ Cloudflare

## ทดลองบนเครื่อง

ต้องติดตั้ง Node.js รุ่น LTS ก่อน

```bash
npm install
npm run dev
```

เปิด URL ที่ Vite แสดงใน terminal

## สร้างไฟล์สำหรับเผยแพร่

```bash
npm install
npm run build
```

ไฟล์เว็บที่พร้อมเผยแพร่จะอยู่ในโฟลเดอร์ `dist`

## เผยแพร่เป็นเว็บส่วนตัวด้วย Cloudflare

1. สร้างบัญชี Cloudflare และเปิดใช้งาน Cloudflare Pages
2. นำโฟลเดอร์โปรเจกต์ขึ้น GitHub repository แบบ Private
3. ใน Cloudflare Dashboard ไปที่ Workers & Pages → Create → Pages → Connect to Git
4. เลือก repository แล้วกำหนด Build command เป็น `npm run build` และ Build output directory เป็น `dist`
5. Deploy แล้วจดโดเมน `*.pages.dev` ที่ Cloudflare สร้างให้
6. เปิด Cloudflare Zero Trust → Access → Applications → Add an application → Self-hosted
7. ใส่โดเมน Pages ที่ได้ แล้วสร้าง policy แบบ **Allow** โดยระบุอีเมลของคุณเท่านั้น
8. เลือก One-time PIN เป็นวิธียืนยันตัวตน แล้วทดสอบเปิดเว็บจากหน้าต่างไม่ระบุตัวตนและจากมือถือ

**สำคัญ:** ต้องสร้างและทดสอบ Access policy ก่อนส่งลิงก์ให้ผู้อื่น และตรวจให้แน่ใจว่าไม่มี hostname หรือ preview deployment อื่นที่เปิดสาธารณะโดยไม่ตั้งใจ

## หมายเหตุ

- การตั้งค่า Cloudflare และการยืนยันอีเมลต้องทำจากบัญชีของเจ้าของเว็บเอง
- ชื่อโดเมนที่กำหนดเองเป็นทางเลือก ไม่จำเป็นสำหรับการทดลอง
- ใช้ตัวละครสมมติที่เป็นผู้ใหญ่และมีความยินยอมเท่านั้น
